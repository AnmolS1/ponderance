Drag in a playlist CSV (from Spotify via Exportify, or Apple and YouTube via TuneMyMusic) and it batch-downloads every track as M4A or high-quality MP3, with optional M3U playlist generation. Everything's bundled into a Windows EXE and a macOS app, because the whole point was that a non-technical person never has to see a Python install or a command line.
