A warm, maximalist storefront for a handmade artisan shop, built with Next.js and configured for static export so there's no server runtime to pay for or worry about. CSS Modules for scoped styling, self-hosted fonts so nothing render-blocks on Google's CDN, and a deploy that drops straight onto Cloudflare Pages.
